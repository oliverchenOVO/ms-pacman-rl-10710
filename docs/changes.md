# 原始版與改良版差異

## 1. Reward Shaping

原始參考版的示範邏輯主要是將正獎勵乘二，並在遊戲結束時給予簡單的加減分。改良版改成：

- 將原始 reward 依比例縮放，保留豆子、能量豆與連續吃鬼之間的價值差異。
- 追蹤長時間沒有得分的步數，對停滯行為給予漸進懲罰。
- 偵測生命數下降並加入死亡懲罰。
- 加入極小的存活獎勵，但控制幅度，避免代理人只求存活而不取分。
- 追蹤吃鬼次數，在 episode 結束時保留相關訓練訊號。
- 後續加入 ALE RAM 訊號，用於辨識豆子、生命與遊戲進度。

設計目標是降低 reward hacking，並讓訓練目標更接近正式評分使用的原始遊戲分數。

## 2. CNN 特徵提取器

| 項目 | 原始版 | 改良版 |
|---|---|---|
| 卷積通道 | 32 → 64 → 64 | 32 → 64 → 128 |
| Residual Block | 無 | 2 個 |
| 特徵維度 | 512 | 1024 |
| Dropout | 無 | 0.1 |
| 輸入 | 遊戲影像 | 4×84×84 灰階 frame stack |

## 3. PPO 設定

| 參數 | 原始示範 | 改良設定之一 |
|---|---:|---:|
| learning rate | 0.0003 | 0.00025 |
| n_steps | 2048 | 128 |
| batch size | 64 | 256 |
| n_epochs | 10 | 4 |
| clip range | 0.2 | 0.1 |
| vf_coef | 未指定 | 0.5 |
| max_grad_norm | 未指定 | 0.5 |
| 並行環境 | 單一 | 8 |

資料夾中保留多條實驗路線，因此不同訓練腳本的參數不一定完全相同。

## 4. 訓練工程

- 使用 Atari 標準化影像前處理與 frame stack。
- 將原始短時間示範訓練擴展為百萬至千萬級 timesteps。
- 加入並行環境、最佳模型保存、定期 checkpoint 及 EvalCallback。
- 支援從既有 PPO 模型續訓。
- 嘗試 pure PPO、RAM-PPO、Wide PPO、Recurrent PPO/LSTM 與 DQN。
- 加入自动播放、影片保存與多局評估流程。

## 5. 結果

- 原始测试影片：430 分。
- 改良版保存影片：10,710 分。
- 最終模型檔：`improved/models/MsPacman-v5_avg10500.zip`。

這是完整流程的成果對照，不是逐項消融實驗。若要判斷每一項修改的獨立效果，仍需固定 random seed，逐一移除修改並重複多次評估。
